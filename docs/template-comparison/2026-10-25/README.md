# LTPR portable comparison pack

Prepared 25 October 2026 from the existing cloud checkout. Start with provenance.json, copy/blocks.json, assets-manifest.csv and constraints.md. This is a review/export package, not a production change or a standalone website.

## Contents

- 199 English copy blocks: 38 profile and 161 media, including navigation and controls. Wording is retained; HTML whitespace is normalized. Exact component source and built HTML are retained for checking punctuation, inline links and line breaks.
- 92 link/embed occurrences (duplicates included). No external destination was newly verified by this extraction. Embedded video is not implied by a video link.
- 127 tracked public images inventoried with bytes, SHA-256 and dimensions when readable; 17 images referenced by these two pages are packaged under public/images. The other available images remain in the repository and have packaged_path=null.
- Source snapshots of existing discovery and media inventories are included unchanged. They are historical evidence, not proof that their missing sources have since arrived.
- Eight requested decision/source paths have individual availability records in missing-sources.json.

Source paths are repository-relative. Source snapshots and rendered HTML are evidence; do not paste the existing page styling into each candidate if the aim is to compare different visual systems. Content extraction is limited to /en/ and /en/media/. Localized/legacy pages are outside this comparison and must remain intact in the production repository.

The repository source and public assets match the approved Forest baseline. Approval is verified against the repository's release record, not a newly recovered original owner conversation. Later frame approvals remain reported approvals as described in constraints.md.

The public images are reusable for this owner's site comparison; public availability does not make third-party press images or broadcast stills freely licensed for unrelated redistribution. Keep review exports private. No original videos, private screenshots, private review HTML or personal Windows source paths were intentionally packaged. Inspect historical source snapshots before sharing outside this project.

MANIFEST-SHA256.json verifies every packaged file except itself. The adjacent ZIP is a transfer artifact; this workspace alone is not durable storage. Store a reviewed, sanitized copy/catalog in GitHub and review assets in private storage. Do not add the ZIP or source masters to the public repository automatically.
