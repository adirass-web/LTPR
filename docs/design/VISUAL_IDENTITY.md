# Approved visual identity

Approved 2026-07-25 for the Astrowind rebuild.

## Composition

- Editorial, portrait-led composition.
- The alternative evidence-led Home prototype is rejected and has been removed from source routes.
- Home uses the locked v3 sequence only: hero, three problems, quiet proof line, private-inquiries close.
- About uses the locked v3 essay structure and the square portrait placement.
- Writing uses the locked v3 argument frames, book, and selected publications.

## Visual rules

- Canvas: `#f6f6f6`.
- Ink: `#000000`.
- Accent: `#02291f`, only for the primary inquiry CTA.
- Geometry: `0px` radius, 1px rules, no shadows, gradients, stock imagery, generic security motifs, or filled iconography.
- Typography: Heebo Regular (`400`) only, self-hosted through the build.

## Bilingual rule

The EN source is locked. Hebrew routes preserve the shared shell, navigation, direction, and metadata but clearly state that native Hebrew source is pending. No machine translation is displayed as approved content.

## Release restrictions

This is an implementation approval, not a production-release approval. The three EN pages remain `noindex` until the citation URLs and approved monochrome portrait files described in `docs/rebuild/WP4_CONTENT_IMPLEMENTATION.md` are present and verified.
